# SGCC Website Starter

## Preview
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `sgcc-website`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

## Before publishing
- Replace the placeholder church address and worship schedule.
- Add the official SGCC email address and Facebook page link.
- In the script near the bottom of `index.html`, replace `REPLACE_WITH_OFFICIAL_SGCC_EMAIL` with the church's actual email address.
- Review the doctrinal summary and formally adopted confession before treating it as SGCC's complete statement of faith.
- Replace the sample Unsplash photographs if you prefer actual SGCC photos.

## Important form limitation
The membership-interest form is currently a front-end starter. It does not save submissions to a database. After adding the official email address, it opens the visitor's email application to prepare an inquiry. For reliable online submissions and an admin view, connect a form service or a secure backend before launch.
